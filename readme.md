# 神话试炼 · Mythic Trials — 规则说明书

> 1~2 人希腊神话桌游 · Low-bit 像素素材 · 网页版（单人挑战 / 双人热座）

## 一、游戏概要

英雄们在 4×4 的神话大地上探索，遭遇并击败神话怪物、收集资源、在神庙购置神器，最终挑战冥界之门后的风暴巨人堤丰。

- **单人挑战**：剧情生存，章节目标 + 计分
- **双人合作**：剧情生存，共享目标，队友倒地可救
- **双人竞争**：德式计分，8 轮限时，总分高者胜

## 二、素材对应

| 素材 | 用途 |
|---|---|
| 4 位英雄立绘 | 可选角色（各有技能） |
| 16 只怪物 + 圣鹿 | 地图遭遇（堤丰为最终 Boss） |
| 6 件神器 | 神庙商店 |
| 黄金/火焰精魄/雷电水晶/月桂 | 货币 / 攻击增幅 / 重掷 / 生命 |

## 三、回合与行动

每回合 **3 行动点（AP）**：

| 行动 | 消耗 |
|---|---|
| 向相邻格移动 | 1 AP（阿尔戈号：每回合首次免费） |
| 探索此地（原地触发遭遇/挑战怪物/接触圣鹿） | **免费** |
| 饮用圣泉（+3 生命） | 1 AP |
| 复活同格队友（合作） | 1 AP + 2 黄金 |
| **精魄换行动**（无行动点时可用，每回合不限次数） | **2 火焰精魄 → 1 临时行动点** |
| 休息（+2 生命，女武神 +3） | 结束回合 |
| 战斗 / 购物 / 拾取 | 不耗 AP |

**精魄增幅结算**：战斗中使用的精魄增幅（每颗 +2 伤害）持续整场战斗，战斗结束时（无论击杀、撤退还是倒地）一次性扣除。

进入未探索格会翻开遭遇：**怪物**（立即战斗）、**资源点**（直接拾取）、**友善圣鹿**（自选 +2 生命或 +2 精魄）。部分格子藏有第二层遭遇。

## 四、战斗

1. 攻击前可用**火焰精魄**增幅（每颗 +2 伤害，至多 3 颗）
2. 掷 **1d6 + 攻击修正 + 神器加成** = 本次伤害
3. 掷骰后可花 **1 雷晶**重掷（少年剑士可免费一次）
4. 怪物存活则**反击**（埃癸斯 -1、暗影神盔免疫首次、风之环免疫一次；免疫类能力对 BOSS 无效、对副 BOSS 减半）
5. **撤退**：退回上一格，怪物伤势保留——普通怪可随时撤退；**副 BOSS 需先发起一次攻击**才可撤退；**BOSS 战不可撤退**

战斗面板会显示怪物**档位**（T1/T2/T3/BOSS）。击杀奖励：分数（T1=1 / T2=2 / T3=3 / 堤丰=5）+ 黄金/精魄/雷晶。

**弹窗**：所有弹窗右上角可「收起」查看地图与资源面板（收起时不能操作，防止误触），点右下角「恢复弹窗」返回，结算弹窗亦可。

**怪物分档（T1/T2/T3）**：怪物按强度分三档，档位决定击杀分数与里程碑资格——
- **T1（1 分）**：萨提尔、花冠树精、岩石巨蟹、战猪、圣猫头鹰
- **T2（2 分）**：阿耳戈斯、独眼巨人、美杜莎、许德拉、弥诺陶洛斯、星空巨熊、西勒诺斯
- **T3（3 分）**：斯芬克斯、特里同，以及两名副 BOSS——**刻耳柏洛斯、卡戎**（第三章讨伐对象，数值更高）；**BOSS（5 分起）**：堤丰

**概率规则**：所有技能触发概率均为六面骰倍数（x/6），与实体桌游一致。

**免疫类能力限制**：暗影神盔与风之环对 BOSS 堤丰**无效**；对副 BOSS（刻耳柏洛斯/卡戎）只能抵消一半伤害（向下取整）；对普通怪全额生效。

## 五、单人挑战 / 双人合作（剧情生存）

按章节顺序推进：

1. **诸神的召唤** — 累计击败 2 只怪物（+2 分）
2. **神器试炼** — 队伍拥有任意 1 件神器（+2 分）
3. **冥界守卫** — 击败刻耳柏洛斯或卡戎（+2 分，解锁冥界之门）
4. **泰坦之怒** — 击败堤丰 → **胜利**

**生存压力**：第 6 轮起堤丰怒火每轮侵蚀全员且加剧（6-7 轮 -1，8-9 轮 -2，第 10 轮起 -3）。

**合作模式**：怪物 HP +2（堤丰 +4）；队友倒地后，队友到同一格花 1 AP + 2 黄金复活（生命 5）；全员倒下即失败。单人模式英雄死亡即失败。

**结算分数** = 奖杯分 + 章节分 + 剩余生命 + 黄金÷3 + 速度奖励（12 − 轮数）

## 六、双人竞争（德式计分）

- 共 **8 轮**，双方轮流行动，热座进行
- **不会死亡**：生命归零 → 送回英雄营地（生命 6）并 **-2 分**，且**立即强制结束其回合**
- **前三个里程碑（同轮可追平）**：首杀 T2 +1 · 首件神器 +1 · 首杀 T3 +2——先抢先得；若后手在**同一轮内**也完成同一里程碑，可追平得分（每人各限一次，过轮作废）。潘多拉魔盒为消耗品，购买**不计入**「首件神器」里程碑
- **堤丰复活机制**：首次击杀 +5 分；此后每击杀一次，堤丰复活并强化（HP +3 / 攻击 +1 / 雷霆概率 +1/6，至多 5/6），讨伐分数 +2（+5→+7→+9……），击杀者被风暴掀回进入 Boss 格前的格子并**强制结束回合**
- **首次击杀堤丰后**：从下一轮起，双方每回合行动点 +1（3→4）
- 终局总分 = 奖杯分 + 神器×2 + 里程碑 + 黄金÷3 +（精魄+雷晶）÷2，高者胜（平分则奖杯多者胜）

## 七、英雄与神器

**英雄**：金发角斗士（攻击+1，战吼爆发）· 自然女武神（风之环免伤，善恢复）· 蓝袍少年剑士（免费重掷）· 红衣镰刀卫士（击杀+1黄金，生命11）

**神器**（神庙购买）：锻造神锤 5金（攻击+1）· 神盾埃癸斯 5金（受伤-1）· 暗影神盔 4金（免疫首次反击，对BOSS无效/副BOSS减半）· 海洋之镜 4金（回合开始+1生命）· 阿尔戈号 6金（每回合首次移动免费）· 潘多拉魔盒 3金（一次性赌注：掷骰 1 受3伤害 / 2-3 空盒 / 4-5 +5黄金 / 6 「希望」+6黄金+2精魄+2生命；结果会显示在商店界面，不计入神器里程碑）

## 八、技术说明

- 全部美术为 **DFPX-RLE1 编码**的 64×64 / 48×48 Low-bit sprite（≤16 色 + RLE），内嵌于单个 HTML 文件，浏览器端实时解码渲染，无外部依赖
- 文件：`index.html`（约 112 KB，双击即玩）
- 已通过无头机器人对局测试：三模式共 54 局自动对局全部正常结束
